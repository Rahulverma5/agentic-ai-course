# Projects

| Project | Level | What it is |
|---|---|---|
| [file-assistant](file-assistant/) | Warm-up | ~150-line agent that manages files in a sandbox folder. The agent loop in its simplest form |
| [shopease-support-agent](shopease-support-agent/) | Capstone (Days 1–15) | Production-style support agent: router, tools, RAG, memory, MCP, guardrails, evals, tracing, streaming API |

The practice notebooks in each `week-*/practice/` folder teach one idea at a time. The capstone is where those ideas come together, the way they would in a real codebase.
